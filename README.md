## Working in this repo

Each build is a standalone Vite + React 18 + TypeScript app in its own `NN-slug` folder.

```bash
# scaffold a new build from _template (installs dependencies too)
npm run new -- 02-colour-mixer

# run it
cd 02-colour-mixer
npm run dev
```

Add `--skip-install` to scaffold without running `npm install`.

**Stack:** Vite · React 18 · TypeScript · Tailwind CSS v4 · Framer Motion · lucide-react · Vercel

Rules every build follows are in [CLAUDE.md](CLAUDE.md).
